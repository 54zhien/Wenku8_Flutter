# Wenku8 iOS 26 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Preserve Wenku8 functionality on iOS 26+ and use native Liquid Glass controls.

**Architecture:** Retain Dart repositories, state and reader. Register iOS implementations of the existing platform channels; isolate Foundation-only protocol rules so they can be executed on Windows. Add grouped native control surfaces with Flutter-owned state and callbacks.

**Tech Stack:** Flutter 3.41.5 / Dart 3.11.3, Swift, UIKit/SwiftUI, URLSession, Keychain, existing audio plugins.

**Spec:** `docs/superpowers/specs/2026-10-16-ios26-port-design.md`

## Global Constraints

- Minimum iOS/iPadOS 26.0. Preserve Android behavior and existing persisted formats.
- No Android binary or signature extraction in iOS. Use currently verified legacy protocol `appver=1.13`.
- Cookie remains native; passwords are never persisted or logged.
- Native glass composition and physical-device acceptance remain unverified until tested on iOS.
- Keep failures as evidence; no weakened assertions, skips or fake demo fallbacks.
- Execute inline as requested by the user: "继续，开工". No per-task permission pauses.

## Review Focus

1. HTTP 200 containing a numeric error or challenge HTML must not become chapter text (Task 1).
2. Logout racing an old account request must not restore the old cookie (Task 2).
3. File-picker cancellation and overlapping presentations must resolve exactly once (Task 3).
4. Rebuilt native controls must not emit duplicate actions or steal scrolling outside their bounds (Task 4).
5. Restarting offline and interrupted audio must preserve reader state (Tasks 2 and 5).
