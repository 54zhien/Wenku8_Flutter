# iOS composition boundary repair

> Execute inline with systematic-debugging, TDD, and verification-before-completion. Review the complete change after verification. No IPA, archive, signing, or delivery in this task.

**Goal:** Retain real UIKit Liquid Glass controls, restore the upstream continuous scroll edge and unchanged push/pop/cover choreography, and remove unnecessary cross-compositor work during movement.

**Base:** `7bfd1edab5fbb7720173c88b06d30bf064ac54e7`. Upstream motion/edge reference: `fe222b071e8bc88918d4cb47c94bb973d148d85f` in sibling `upstream-review`.

## Evidence and limits

- The user reports every repeated book push/pop stutters, plus other page transitions and top blur defects. All motion/low-performance switches were already confirmed off.
- Current edge emits up to nine independent BackdropFilters instead of the upstream single feathered Gaussian. Existing continuity acceptance is expected to reject the band approximation; it was not a passing native-quality result.
- Pinned engine `052f31d115eceda8cbff1b3481fcde4330c4ae12` propagates backdrop filter rect/sigma into visited UIKit views. `ChildClippingView.applyBlurBackdropFilters` creates or updates native effect views. It does not propagate the Flutter child's dstIn feather. Ancestry isolation alone cannot solve this.
- Admission only delays newly entering native controls. Source-page controls, return routes, and native bars remain live in moving page composition. Unit mocks cannot establish native frame cost or visible return correctness.
- Physical root-cause attribution (CPU/raster/Core Animation) is still unmeasured. Do not turn structural evidence into a claim that physical stutter is solved.

## Chosen boundary

Use one passive full-edge native plane containing the SAME untinted Gaussian extracted by the pinned engine, with the original eight smoothstep-sampled alpha stops and bottom sigma nudge. Flutter foreground paints above it; both Flutter and native body content paint below it. Keep real Liquid Glass platform layers throughout primary/secondary push, pop and interactive return. Do not use system-material tint, replace native glass with raster imitations, alter original timings/choreography or clear ancestor masks.

The app's Clip.none root Navigator and horizontal Cupertino transforms allow this narrow plane without a parent-mask hook. Verify the actual engine-owned wrappers and all ancestors before attaching the effect, disable the actual passive platform wrappers' hit planes, reuse the effect during horizontal motion, and recreate only for size/profile/attachment changes. Reject unsupported ancestry rather than expose an unmasked rectangle.

The normal shared path suppresses snapshot capture entirely, does not instantiate the legacy per-control edge adapter, and emits no Flutter BackdropFilter. The prior route-texture experiment remains opt-in for regression diagnostics only; its measured synchronous readback cost makes it unsuitable as the default repair. The stationary texture experiment is also rejected because omitting PlatformViewLayer detaches native touch handling.

The user requires the original pure Gaussian and explicitly rejects UIKit system-material substitution. Real Metal/native pixel assertions and original route contracts must pass on the promoted production factory. A same-simulator delivered/edge-only/shared timing comparison and physical-device acceptance remain separate requirements; structural or pixel results do not prove the reported physical jank solved.
